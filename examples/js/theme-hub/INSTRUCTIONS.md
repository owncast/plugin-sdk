# Theme Hub

Pick a viewer theme and apply it to your whole Owncast page with one click.

## What you'll see when enabled

A **Themes** page in this plugin's admin settings listing the available themes, each with a name and short description, plus a "None" option. Selecting one applies it immediately; the change shows up on the viewer page on its next load.

The bundled themes are:

- **Midnight** — a deep indigo dark theme with cool blue accents.
- **Sunset** — a warm dark theme with orange and magenta highlights.
- **Forest** — an earthy green theme with a light parchment content area.

## How it works

The selected theme's CSS is injected into your site's core styling (the same place the Appearance settings live), so it restyles the entire viewer UI — background, action colors, chat, buttons, and corner radius. Choosing **None** removes the plugin's styling and returns you to Owncast's default theme.

Your choice is saved, so it sticks across restarts until you change it.

## Using it as a starting point

The three themes are hardcoded in the plugin, but the plugin is structured so the catalog could just as easily be downloaded from a remote theme registry. It's a working example of how to build a "browse and apply a theme" experience as an Owncast plugin.
