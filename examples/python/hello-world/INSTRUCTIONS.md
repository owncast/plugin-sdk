# Hello World

The smallest possible Owncast plugin. It registers successfully and does nothing else: no event handlers, no UI, no permissions.

## How to use it

1. Enable the plugin in **Admin → Plugins**.
2. ...that's it. There's no visible behavior. If the plugin loads and shows as enabled without error, your install path works end to end.

Use this as the starting skeleton for a new plugin: copy it, then add one handler at a time.

## Permissions

None.
